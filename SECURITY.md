# Security

## Reporting a vulnerability

Please do not include exploit details, credentials, or private trading data in a public issue.

Use [GitHub's private vulnerability reporting](https://github.com/jakkarudev/fx-calculator/security/advisories/new) when enabled. If it is unavailable, use the contact options on [jkrdev.com](https://jkrdev.com) to request a private reporting channel before sharing details.

Include the affected commit or version, platform, reproduction steps, expected impact, and a minimal example with synthetic data. The project does not promise a response SLA.

## Scope

There is no defined release support matrix yet. Reports should target the current default branch. Local preference storage is not encrypted, and the app does not store brokerage credentials or execute trades.

Ordinary calculation defects belong in [GitHub Issues](https://github.com/jakkarudev/fx-calculator/issues) with non-sensitive reproduction data.
